# EverythingPDF

Sign, fill in and edit PDFs on your computer — everything stays offline.

## Install

**Windows:** download `EverythingPDF-…-Windows-x64-Setup.exe` from the [latest release](https://github.com/mihaicojocaru21/EverythingPDF-releases/releases/latest) and run it.
No administrator rights are needed. If Windows shows "Windows protected your PC", click **More info → Run anyway**.

**Mac:** download `EverythingPDF-…-Mac.dmg` from the [latest release](https://github.com/mihaicojocaru21/EverythingPDF-releases/releases/latest), open it and drag the app to Applications.
The first time, right-click the app → **Open**.

## Updates

The app checks this page at start and every few hours. When a new version is available it shows
**"EverythingPDF … is available"**. On Windows, click **Install Update** and then **Restart Now**.

This repository holds only the installers.
